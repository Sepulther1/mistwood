# Economy Overview (Simulation)

## Modules (first pass)
- **Currency & Accounts**: player wallets, NPC banks, simple ledger.
- **Transactions**: transfers, escrow, fees, interest.
- **Markets**: order book for items/resources; later: mock stocks/options.
- **Contracts**: time-locked agreements (quests, loans).
- **Oracles (simulated)**: world events driving prices (weather, scarcity).

## Safety Rails
- Simulation only; no withdrawal to real money.
- Clear in-game disclosures: “Educational simulation, not finance.”

## First Milestone
- Single currency, basic bank, deposits/withdrawals, simple market for 2–3 resources.
