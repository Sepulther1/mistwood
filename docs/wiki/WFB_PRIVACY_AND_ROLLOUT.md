# WFB Privacy & Organization Rollout

- **WFB content is private** to the local contributor and their paired assistant.
- The organization may still improve shared systems using *signals* (counts, statuses, anonymized metrics) derived from private work.
- **No raw WFB content** is shared org-wide until codified as public docs/policy/case studies.
- We may run limited A/B experiments that influence assistants’ behavior, but **never** require viewing private files.
- Once an approach is validated, we publish it as policy, runbook, or tutorial.

## What gets shared vs not
- **Shared:** dashboard badges, counts (e.g., “3 sealed handoff bundles”), pass/fail of preflight, anonymized timing.
- **Not shared:** raw text, secrets, filenames revealing private work, specific chat logs.

## Opt-out
- Any contributor may opt out of experiments; they still receive baseline policies.

## Incident handling
- If any private data leaks, halt experiment, rotate keys if relevant, document a case study (sanitized), update policy and checks.
