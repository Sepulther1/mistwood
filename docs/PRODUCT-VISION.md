# Mistwood – Product Vision

## Big Idea
A joyful MUD-like world where players learn systems thinking. We simulate **banking, markets, contracts, currencies**, etc., safely inside the game. It’s fun first; education by doing.

## Why it matters
- Gives people a low-risk sandbox to learn complex systems.
- Surfaces reusable tooling (ops, performance, editor flows) we can package for others.

## Non-Goals (for now)
- No real-money finance. No token sales. No financial advice.

## Differentiators
- Game-first UX; real mechanics modeled simply.
- Opinionated dev ergonomics (VS Code tasks, logs, low friction).
- Open artifacts: docs, ADRs, and packable templates.

# Product Vision

Audience: systems-curious players who love emergent worlds.

Pillars: Fun-first economy, civic building, teach-through-play, kindness.

Non-Goals: P2W monetization; opaque grind.

90-Day Wins: stable loop, daily quests, first city projects, site + Discord live.
