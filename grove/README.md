Grove — Willow Loop

Willow Loop is our adaptive planning engine:

Synergy Scout (forward-looking): scan current blocks to discover complementary opportunities with upcoming/adjacent work.

Perspective Drift (retrospective): compare past→current→planned blocks to reprioritize as tools/processes change.

Artifacts:

grove/state.json — normalized issues/PRs/blocks with statuses.

web/static/telemetry/grade.json — BI-lite grade shown on /dashboard/.

docs/STATUS.md — human summary dump for each cycle.

Trigger cadence: daily (GitHub Action), manual on demand, and on merges.
